# Agent Foundation

Reusable, neutral operating foundation for maturing OpenClaw agents after initial bootstrap.

## What it is
A portable core for agents that are already alive and minimally configured:
- OpenClaw installed
- at least one model working
- workspace created
- bootstrap done
- first user/agent contact already happened

From that clean starting point, the agent can read this foundation and apply it to itself.

## What it includes
- core principles
- memory system
- model routing
- subagent policy
- verification
- housekeeping
- error learning
- promotion policy
- new-agent adoption guidance
- routing vs isolation guidance
- templates

## What it is not
- not an OpenClaw installer
- not a replacement for onboarding
- not a clone of any specific agent or user

## Layout
Core docs live under `docs/agent-foundation/`.

## Status
Current maturity: usable core, intended to evolve through changelog + roadmap.
