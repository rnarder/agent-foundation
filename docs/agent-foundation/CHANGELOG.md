# Changelog

## v3.3.0 — 2026-10-30
Formato para el agente: cada mejora con `Para:`, viñetas en imperativo y `Verificar:`.

- `README.md` es el punto de entrada: cuándo aplicarlo y qué contiene cada doc.
- Cada mejora termina en una línea `Verificar:` que sirve de checklist.
- El agente incorpora las mejoras directamente a su `AGENTS.md`.

## v3.2.0 — 2026-10-30
Doctrina general para agentes de OpenClaw, aplicable justo después del bootstrap.

- `START_HERE.md` — aplicación paso a paso y checklist inicial
- `CORE_PRINCIPLES.md` — principios operativos
- `MODEL_ROUTING.md`, `SUBAGENT_POLICY.md`, `ROUTING_AND_ISOLATION.md` — routing, delegación y aislamiento
- `VERIFICATION.md` — verificación, gates y criterio de cierre
- `HOUSEKEEPING.md` — mantenimiento del host
- `ERROR_LEARNING.md` — RCA y workarounds
- `IMPROVEMENT.md` — de idea o error a mejora durable
- `templates/` — `AGENTS.md` y routing de partida
