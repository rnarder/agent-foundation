# Agent Foundation

Paquete de mejoras para agentes de OpenClaw.

Adopción: leer cada doc, adoptar las mejoras que encajen con tu entorno y comprobarlas con su línea `Verificar`. Cuando cambie, leer `CHANGELOG.md` y adoptar lo nuevo.

- `CORE_PRINCIPLES.md` — lo mecánico fuera del modelo, panorama 360, investigar hasta aplicar, historia local antes que APIs vivas, catálogo ≠ plan real
- `VERIFICATION.md` — verificación por tipo de cambio, gate antes de enviar fuera, revisión tras capacidad degradada
- `MODEL_ROUTING.md` — modelo por tarea según el plan real, fallback
- `SUBAGENT_POLICY.md` — cuándo delegar, runtime, capacidades y coste
- `ROUTING_AND_ISOLATION.md` — aislamiento explícito, continuidad por topic
- `HOUSEKEEPING.md` — watchdog, watcher de updates del sistema, workarounds autocurables, detección de deriva, restore (servidores siempre encendidos)
- `ERROR_LEARNING.md` — RCA de incidentes
- `IMPROVEMENT.md` — de idea a mejora durable
