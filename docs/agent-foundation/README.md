# Agent Foundation

A package of improvements for OpenClaw agents.

Adoption: read each doc, adopt the improvements that fit your environment and check them with their `Verify` line. When it changes, read `CHANGELOG.md` and adopt what is new.

- `CORE_PRINCIPLES.md` — mechanical work out of the model, 360 overview, research until applied, local history before live APIs, catalog ≠ real plan
- `VERIFICATION.md` — verification per change type, gate before sending out, review after degraded capacity
- `MODEL_ROUTING.md` — model per task according to the real plan, fallback
- `SUBAGENT_POLICY.md` — when to delegate, runtime, capabilities and cost
- `ROUTING_AND_ISOLATION.md` — explicit isolation, per-topic continuity
- `HOUSEKEEPING.md` — watchdog, system update watcher, self-healing workarounds, drift detection, restore (always-on servers)
- `ERROR_LEARNING.md` — incident RCA
- `IMPROVEMENT.md` — from idea to durable improvement
