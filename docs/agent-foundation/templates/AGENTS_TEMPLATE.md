# AGENTS.md Template

## Session Startup
1. Read `SOUL.md`
2. Read `USER.md`
3. Read `memory/YYYY-MM-DD.md` (today + yesterday)
4. In main/private session only: read `MEMORY.md`
5. Search memory before answering about prior work, decisions, preferences or todos

## Operating Rules
- Prefer simple systems over clever brittle ones
- Prefer mechanical automation over LLM loops
- Use subagents only when they add leverage
- Keep routing policy in workspace files
- Verify important changes before declaring success
- Write durable operational rules to files

## Post-Bootstrap Maturation
Use local docs and the agent's operational files to:
- improve memory hygiene
- clarify routing and isolation
- strengthen verification
- refine model usage
- document durable lessons
