# Skillify

A short manifesto for Agent Foundation.

## The problem

Most agent reliability is still vibes-based.

When an agent fails, the usual response is:
- tweak the prompt
- add another instruction
- make the system message longer
- hope it remembers next time

That does not scale.

A good agent should not depend on remembering a bug inside a conversation.
A good agent should become structurally less likely to repeat it.

## The idea

**Skillify** means turning a useful solution or a repeated failure into durable system capability.

Not just a patch.
Not just a note in chat.
A real capability.

That capability may become:
- a skill
- a deterministic script
- a test
- a routing rule
- memory
- an operational document

## The rule

If a solution matters enough that you want it again, it should not live only in latent space.

## Latent vs deterministic

This is the core distinction.

### Deterministic work
Send this to code, not model improvisation:
- exact lookup
- parsing
- timestamp math
- validation
- filtering
- dedupe
- health checks
- routing logic

### Latent work
Keep this in model space:
- judgment
- synthesis
- prioritization
- interpretation
- tradeoff decisions

A healthy agent knows the difference.
A healthy framework reinforces it.

## The workflow

Skillify is a promotion loop:

1. a failure happens, or a valuable solution appears
2. the mechanical part is extracted from the model
3. the process is captured in a skill or operational rule
4. routing is made explicit
5. verification is added
6. the knowledge becomes durable

The result is not “the model learned.”
The result is “the system changed.”

## Why this fits Agent Foundation

Agent Foundation already has the right raw materials:
- skills
- routing
- memory
- verification
- explicit structure

Skillify supplies the missing discipline:

> how a one-off success or failure becomes permanent infrastructure.

## What Agent Foundation should adopt

At minimum:
- skillify as a core principle
- a minimal promotion checklist
- a bias toward deterministic solutions for mechanical tasks

Later:
- reachability checks
- overlap audits
- resolver evals
- drift detection

## What skillify is not

Skillify is not bureaucracy.
It is not “write a skill for every tiny thing.”
It is not a license to over-engineer.

It is the rule that says:

> do not keep paying for the same mistake twice.

## One-line summary

**Agent Foundation defines the structure of an agent. Skillify defines how that structure learns from reality without depending on improvisation.**
